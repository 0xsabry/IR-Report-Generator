# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please report it responsibly:

1. **Do NOT** open a public issue
2. Use [GitHub Security Advisories](https://github.com/0xsabry/IR-Report-Generator/security/advisories/new)
3. Include description, reproduction steps, and potential impact

## Scope

This is a **client-side** application — security concerns include:

- XSS via user-provided IOC data or finding content
- localStorage data exposure
- Report content injection

## Response

- Acknowledgment within 48 hours
- Fix within 7 days for critical issues
